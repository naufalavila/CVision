# **{ CVision }**

Upload a PDF resume. Get AI feedback. Fix your CV. Download the report.

## **What it does**

- You upload a resume (PDF only)
- AI reads it
- AI gives: Overview, Strengths, Weaknesses, Recommendations
- You download the results

## **Features**

- Pick any AI model (via OpenRouter)
- Choose output language: English or Indonesian
- Clear, direct feedback
- One-click download

## **Tech Used**

- Python
- Streamlit
- OpenRouter API

## **How to Run**

1. Get an OpenRouter API key
2. Upload the API key inside the .env file (make one if it doesn't exist)
3. Open terminal in project folder
4. Run: `pip install -r requirements.txt`
5. Run: `streamlit run app.py`
6. Open the local link in your browser

## **How to Use**

1. Upload PDF resume
2. Select AI model
3. Pick language (EN/ID)
4. Click **Analyze**
5. Read output analysis
6. Click **Download** to download output
